tmux Cheatsheet · Fundamentals

Terminal multiplexer — keep sessions alive, split your terminal, switch between windows.

Prefix key Ctrl + b
Press, release, then type the command
Ctrl+b = prefix (press first) x = regular key tmux … = shell command then = press in sequence

Quick start recipe  ·  In any shell, type tmux new -s work to start. Split a vertical pane with Ctrl+b %, jump around with the arrow keys, then detach with Ctrl+b d. Close the terminal — your work keeps running. Come back any time with tmux a -t work.

Stuck? Press Ctrl+b then ? for the full shortcut list (q to exit). To kill tmux entirely, exit each shell with exit or run tmux kill-server.
